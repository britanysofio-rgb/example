# Patient log

Structured medical notes created from dictation. Each note is a dated
markdown file built from `TEMPLATE.md`; sections that were not dictated
are omitted, not filled in.

**De-identification rule:** notes in this log must never contain patient
names, dates of birth, MRNs, contact information, or other PHI. Patients
are referred to by age and sex only (e.g., "58-year-old male").
